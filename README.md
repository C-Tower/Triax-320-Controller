# Triax-320-Controller
A program to control a Triax 320 spectrometer using GPIB communction.

This program has been tested on a windows 10 computer to control a Horiba Triax 320 legacy spectrometer. 
The GPIB was connected to the computer using a GPIB to usb connector from Agilent (now Keysight) and utilizing the visa64.dll included with the driver install.

The program is written in python3 and requires:
-pyvisa
